# UPay 收单 API 对接问题汇总

## 总结

当前支付 API 对接测试阶段存在多项阻塞与缺失问题，收款、Webhook、账务全流程均无法完整验证，共 3 个 P0、2 个 P1、3 个 P2 待跟进。

## 问题清单

P0:
开发环境收银台生成虚拟地址而非真实钱包地址，无法完成付款入账；
测试环境缺少公网域名，VPS 上的服务无法完成从发单到到账的全流程测试；
开发管理后台缺少模拟到账 mock 接口，Webhook 及账务流程无法对接调试；

P1:
缺少退款接口，商户收款被 KYC / AML 卡住时无途径发起退款；
缺少账务推送和账务分页查询接口；

P2:
缺少通过商户方订单 ID 查询支付详情的接口，订单超时或出错时商户侧不可见；
API 文档中生产环境 URL 和沙盒环境 URL 均有误；
文档列出创建、列表、查询、取消四个接口，实际仅有创建和查询两个，缺少列表和取消；

## 已对接项

1. 创建订单
2. 查询订单
3. Webhook 到账与部分到账

## 待对接项

1. 商户发起退款
2. 商户发起法币提现
3. 查询商户头寸
4. 结算 Webhook 推送、已提现 Webhook 推送
